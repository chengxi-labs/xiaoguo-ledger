# 架构说明

本文描述小果管钱的模块划分、关键数据流，以及那些「看起来多余、其实必须」的实现细节。

## 1. 总体形态

```
web/  ──同步──▶  android/app/src/main/assets/www/
 │                        │
 │                        ▼
 │              WebView（伪域名 https://appassets.local）
 │                        │
 └─ 可直接用浏览器打开     ├─ LocalAssetClient → getAssets()
                          └─ DownloadBridge → MediaStore / Downloads
```

同一份前端代码有两个宿主：

| 宿主 | 资源来源 | 导出实现 | 启动方式 |
| --- | --- | --- | --- |
| 浏览器 / PWA | HTTP 静态服务或 Service Worker 缓存 | `Blob` + `<a download>` | `node web/server.js` |
| Android | APK 内的 `assets/www/` | `XiaoguoAndroid.saveToDownloads()` | `MainActivity.onCreate()` |

两端的行为差异只在导出路径上，其余逻辑完全一致。

## 2. Android 层

### 2.1 MainActivity 的职责

`android/app/src/main/java/com/xiaoguo/ledger/MainActivity.java` 只有约 270 行，做四件事：

1. **建 WebView 并收紧配置**
   - `setAllowFileAccess(false)`、`setAllowContentAccess(false)`：禁止 `file://` 越权读取
   - `setMixedContentMode(MIXED_CONTENT_NEVER_ALLOW)`：不加载混合内容
   - `setSupportZoom(false)`、`setBuiltInZoomControls(false)`：把缩放交给页面自身的 viewport
   - `WebView.setWebContentsDebuggingEnabled(false)`：正式包关闭远程调试
   - UA 追加 `XiaoguoLedgerAndroid/1.0`，前端据此判断是否原生宿主

2. **用伪域名提供本地资源**

   页面地址是 `https://appassets.local/index.html`，但该域名并不存在。`LocalAssetClient.shouldInterceptRequest()` 拦截所有请求，把 `path` 映射到 `assets/www + path`，用 `getAssets().open()` 读出字节流返回。

   为什么不直接 `loadUrl("file:///android_asset/www/index.html")`？
   因为 `file://` 下 `fetch("./imports/shark-ledger.json")` 会被当作跨域请求拦掉，而内置账目导入正是靠 `fetch` 实现的。用 https 伪装域名可以保留正常同源语义，同时完全离线。

   `shouldOverrideUrlLoading()` 对非 `appassets.local` 的链接交给系统浏览器打开，避免 WebView 内部跳出应用。

3. **导出桥接**

   `DownloadBridge.saveToDownloads(filename, mimeType, base64)` 通过 `@JavascriptInterface` 暴露给页面。写入分两条路径：
   - API 29+：`MediaStore.Downloads` + `IS_PENDING` 两段式写入
   - API ≤ 28：公共 `Downloads` 目录 + `MediaScannerConnection.scanFile()` 通知媒体库，并在此路径上请求 `WRITE_EXTERNAL_STORAGE`

   文件名统一过 `sanitizeFilename()`，把 `\/:*?"<>|` 替换为 `_`。

4. **生命周期**

   `onDestroy()` 里移除 JS 接口并 `destroy()` WebView；`onBackPressed()` 优先让 WebView 回退，回退不了才退出应用。

### 2.2 构建配置

| 项 | 值 | 位置 |
| --- | --- | --- |
| applicationId | `com.xiaoguo.ledger` | `android/app/build.gradle` |
| minSdk / targetSdk / compileSdk | 26 / 35 / 35 | 同上 |
| versionCode / versionName | 4 / 1.0.3 | 同上 |
| AGP / Gradle | 8.7.3 / 8.9 | `build.gradle` / `gradle/wrapper/` |
| 依赖 | 无（未启用 AndroidX、无第三方库） | — |

签名配置是**条件挂载**的：

```groovy
if (keystorePropertiesFile.exists()) {
    signingConfigs { release { ... } }
}
```

文件不存在时不挂载签名，`assembleDebug` 回退到 Android 默认调试密钥，`assembleRelease` 产出未签名包。这样克隆仓库无需任何密钥即可构建。

### 2.3 权限

| 权限 | 用途 |
| --- | --- |
| `INTERNET` | WebView 以 https 方案加载本地资源所需；应用无任何出站请求 |
| `WRITE_EXTERNAL_STORAGE`（`maxSdkVersion=28`） | 仅 API ≤ 28 的导出路径需要 |

`allowBackup="false"`：账本不进系统备份通道。

## 3. 前端层

`web/app.js` 约 800 行，按职责分成六段：

| 段落 | 关键函数 | 说明 |
| --- | --- | --- |
| 常量与状态 | `STORAGE_KEY`、`CATEGORIES`、`state` | 单一状态对象，无状态库 |
| 存储 | `loadTransactions()` / `saveTransactions()` | 直接读写 `localStorage`，读取时做字段清洗 |
| 渲染 | `render()`、`renderCategoryStats()`、`renderMonthPicker()` | 每次状态变化整体重绘列表与汇总，用 `replaceChildren()` 而非增量 diff |
| 记账 | `addTransaction()`、`deleteTransaction()` | 表单提交与列表删除 |
| 导出 | `exportTransactionsCsv()`、`exportTransactionsJson()` | 生成文本 → `downloadFile()` 分派到原生桥或 Blob |
| 导入与迁移 | `mergeTransactions()`、`importBundledLedger()`、`applyCategoryMigrations()` | 按 `id` 去重合并，并按映射表修正旧分类与日期 |

### 3.1 渲染策略

没有虚拟 DOM，也没有局部更新。做法是：

```
用户操作 → 改 state → saveTransactions() → render() → 重建 DOM
```

数据量在千级以内（真实使用约 800~2000 条），整体重绘的耗时远低于一帧预算。换取的是零抽象、零依赖、改代码不用重建。

搜索走同一套渲染：`state.searchQuery` 变化后 `render()` 会切换到「全历史搜索结果」模式，并按 `state.searchLimit` 分批加载（每次 +60 条）。

### 3.2 货币与精度

金额在录入时 `Math.round(Number(value) * 100) / 100` 归一到两位小数，展示统一用 `formatMoney()` 加 `¥` 前缀。没有引入定点数库 —— 记账场景的金额量级与两位小数约束下，二进制的表示误差在四舍五入后不可见。

### 3.3 离线

`web/sw.js` 用「缓存优先、命中即返回；未命中则请求并回填」的策略缓存 App Shell。`CACHE_NAME` 变更（当前 `xiaoguo-ledger-v14`）会在 `activate` 阶段清掉旧缓存，因此发版时改版本号即可让用户拿到新资源。

## 4. 数据流总览

```
           ┌── 手动记账 ──────────────┐
           │                          ▼
内置演示 JSON ──fetch──▶ mergeTransactions() ──▶ state.transactions
                                    │              │
旧备份 JSON ──导入──────────────────┘              ├─▶ localStorage
                                                   │
                                                   ├─▶ render() → DOM
                                                   │
                                                   └─▶ 导出 CSV / JSON
                                                        │
                                    ┌───────────────────┴──────────────┐
                                    ▼                                  ▼
                          XiaoguoAndroid 桥接                  Blob + <a download>
                          （Android：Downloads 目录）           （浏览器）
```

## 5. 已知取舍

| 取舍 | 现状 | 若未来要改 |
| --- | --- | --- |
| 存储用 `localStorage` | 简单、同步、容量约 5 MB | 数据量过万条时迁移到 IndexedDB，需要一次迁移逻辑 |
| 每次全量重绘 | 代码极简 | 列表超过数千条时改为分页渲染（`searchLimit` 已经是雏形） |
| 前端与 Android 资源镜像 | 一个脚本 + CI 校验 | 可改为构建期由 Gradle 任务拷贝，但会引入跨目录耦合 |
| 不做数据加密 | 依赖系统沙箱 | 敏感场景可加 WebCrypto + 口令派生密钥 |
| 无后端 | 无法多设备同步 | 若加同步，必须同时提供端到端加密，否则违背项目定位 |
